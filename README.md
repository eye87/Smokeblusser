# Smokeblusser homepage

Responsive statische homepage, opgebouwd uit de aangeleverde PDF en SVG.

Open `index.html` rechtstreeks in een browser, of serveer deze map via een lokale webserver. Alle gebruikte beelden, illustraties en het logo staan lokaal in `assets/`; er zijn geen externe afhankelijkheden.

## Bestanden

- `index.html` — semantische pagina-inhoud
- `styles.css` — desktop-, tablet- en mobiele layout
- `script.js` — mobiel menu en sfeerbeeld-dialog
- `assets/` — uit het bronontwerp geëxtraheerde beelden en vectorassets
